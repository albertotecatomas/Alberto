📘 Como usar este simulador? (Guia Completo) ▼

🎯 Para Iniciantes:

  • Comece simples: Use apenas os campos básicos primeiro
  • Valor a Investir: Digite quanto dinheiro pretende aplicar
  • Horizonte: Escolha por quantos meses quer manter o investimento
  • Variação esperada: Use os botões rápidos (+5%, +10%, etc.)
  • Clique em "Calcular Simulação" para ver os resultados

📈 Explicação dos Indicadores:

Rentabilidade Nominal: Ganho/pedida sem considerar a inflação (valor bruto)
Rentabilidade Real: Ganho/perda REAL após descontar a inflação (poder de compra)
Inflação Ajustada: Quanto a inflação "comeu" do seu rendimento
Impacto Cambial: Efeito da variação do câmbio no seu investimento

💡 Dicas Importantes:

  • Rentabilidade REAL é o que importa: Se for negativa, você perdeu poder de compra
  • Compare cenários: Use a seção de comparação para testar diferentes variações
  • Considere a inflação: Em Angola, a inflação histórica é alta - não ignore!
  • Diversifique: Use a distribuição de carteira para simular investimentos múltiplos
